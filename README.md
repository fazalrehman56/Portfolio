# Fazal Rehman | Portfolio Website

My personal developer portfolio — designed and coded from scratch to showcase my projects, skills, and experience as a frontend developer.

🔗 **Live site:** [portfolio-steel-theta-49.vercel.app](https://portfolio-steel-theta-49.vercel.app/)

## About This Project

A dark, techy single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools. Designed to load fast, look clean, and put real, deployed project work front and center.

## Features

- **Custom animated cursor** with a trailing ring effect that follows mouse movement
- **Scroll-triggered fade-in animations** using the Intersection Observer API — project cards, skill items, and stat boxes animate into view as you scroll
- **Skills section** with an honest, tiered breakdown (Strong / Intermediate / Learning / Familiar) rather than overstating proficiency
- **Projects showcase** linking out to live demos and GitHub repos for each real project
- **Direct contact section** with click-to-call, click-to-email, and GitHub links
- Fully responsive layout across devices

## Tech Stack

| Layer | Tool |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | Vanilla JavaScript (Intersection Observer API) |

No frameworks or libraries — built to demonstrate strong fundamentals in core web technologies.

## Sections

- **Hero** — introduction and quick stats (semester, projects, years coding)
- **About** — background and what I work with
- **Skills** — tech stack with honest proficiency levels
- **Projects** — MyBindle App, this Portfolio, React Social Media App, Myntra Clone, Spotify Clone
- **Contact** — phone, email, and GitHub
